REQUISITOS POR AULA

AULA 02 - GIT E GITHUB, SCSS, BOX MODEL E FLEXBOX
- Repositório PÚBLICO no GitHub com histórico de commits do grupo;
- Estilização com SCSS: variáveis, aninhamento (nesting) e pelo menos 1 mixin;
- Layout com Flexbox (menu, cards, galeria ou similar);
- Aplicação de Box Model (padding, margin, border e box-sizing: border-box).

AULA 03 - RESPONSIVIDADE + FUNDAMENTOS DE JAVASCRIPT
- Páginas responsivas: meta viewport, abordagem mobile-first e pelo menos
  2 media queries;
- Layout adaptado a pelo menos 3 tamanhos de tela (celular, tablet, desktop);
- JavaScript aplicado na lógica do projeto: variáveis (let/const), tipos de
  dados, condicionais, loops, arrays, objetos, funções e eventos.

AULA 04 - REACT: COMPONENTES, HOOKS E ROTAS
- Projeto React criado com Vite;
- Componentização: pelo menos 3 componentes reutilizáveis na pasta components;
- useState em pelo menos uma interação (formulário, filtro, contador, lista);
- Renderização de listas com map() e key;
- Rotas com React Router: pelo menos 3 rotas e menu de navegação com Link.

AULA 05 - CONSUMO DE API, NEXT.JS COM TAILWIND, TESTES E DEPLOY
- Consumo de API pública com axios (requisição GET), usando useState +
  useEffect e renderização com map;
- Página institucional do projeto criada em Next.js e estilizada com
  Tailwind CSS (responsividade com sm/md/lg), também publicada na Vercel;
- Pelo menos 2 testes: Jest (função) e/ou React Testing Library (componente);
- Deploy do projeto React e da página Next na Vercel, com links públicos.
