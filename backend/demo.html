Por que validar os dados

  • Erros inesperadosUma data como "amanhã" chegava até o banco e voltava como erro 500.
  • VulnerabilidadesBarrar dados fora do formato é uma camada contra SQL injection e XSS, somada às queries parametrizadas ($1) e ao escape na exibição.
  • Dados corrompidos no bancoSem validação, um e-mail nao-e-email e uma monitoria com 0 vagas eram salvos como válidos.
